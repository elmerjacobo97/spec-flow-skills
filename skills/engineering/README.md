# Engineering Skills

| Skill | What it does |
| --- | --- |
| [`spec`](./spec/SKILL.md) | Guides you through a 4-phase spec-driven design session and saves the result to `specs/NN-slug.md`. |
| [`spec-edit`](./spec-edit/SKILL.md) | Edits an existing spec in place — guided and minimal: impact analysis across sections, one preview confirmation, coherence check, and it never touches the state line. |
| [`spec-impl`](./spec-impl/SKILL.md) | Implements an `Aprobado` spec group by group on a `spec-NN-slug` branch (or the ticket branch), pausing after each group for review and commit; ticks plan checkboxes inside the spec and verifies acceptance criteria at the end. `--one-shot` skips the pauses. |
